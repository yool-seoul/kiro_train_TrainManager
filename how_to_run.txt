==========================================
 Train Manager 실행 방법 (로컬 터미널)
==========================================

필요: Python 3.10 이상 (권장 3.13). 확인: python3 --version


------------------------------------------
[1] 최초 1회 - 가상환경 + 의존성 설치
------------------------------------------
cd /Users/imac_home/Work/kiro_train_TrainManager
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

  ※ 이미 .venv 가 있으면 이 단계는 건너뛰어도 됩니다.


------------------------------------------
[2] .env 파일 확인 (프로젝트 루트에 있어야 함)
------------------------------------------
  - 없으면 .env.example 을 복사해서 값을 채웁니다:  cp .env.example .env
  - 주요 값:
      TRAINMGR_DATA_SOURCE=mock   (가짜 데이터, 테스트용 / 실제 예약 X)
      TRAINMGR_DATA_SOURCE=live   (실제 KTX/SRT 연동 - 실제 좌석 선점 주의)


------------------------------------------
[3] 서버 실행
------------------------------------------
source .venv/bin/activate                                  (터미널 새로 열 때마다)
uvicorn app.main:app --host 127.0.0.1 --port 8000

  브라우저 접속:  http://127.0.0.1:8000
  종료:           Ctrl + C


------------------------------------------
한 줄로 실행 (activate 생략)
------------------------------------------
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000


------------------------------------------
참고
------------------------------------------
  - 코드 자동 반영:  뒤에 --reload 추가
  - 테스트 실행:     .venv/bin/python -m pytest tests/ -v
  - mock <-> live 전환: .env 의 TRAINMGR_DATA_SOURCE 수정 후 서버 재시작 필수
                        (설정은 서버 시작 시점에 고정됨)
